The objective is to design, implement, execute and evaluate automated tests based on the approved Test Plan.  
Selected [test cases] (#id-test-case) will be automated using Robot Framework and Playwright.   

### ID Test Case
TC-01 Login with valid credentials
TC-04 Login with incorrect credentials
TC-10 Add a product to the cart

## Tools and Technologies
- Robot Framework
- Playwrigth
- GitHub for version control and collaboration
    
## Test Strategy  
Functional testing verifies that the application's main features work correctly.  
Positive testing verifies valid input (TC-01 and TC-10).  
Negative tseting verifies how the application handles invalid input (TC-04).  
Automated testing is used for repeatable workflows.
